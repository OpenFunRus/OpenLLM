# Ubuntu 24.04 + RTX 3090 24GB — headless AI server (Dirk)

Отдельная VM. Успешные шаги записываются сюда.  
Порядок: подготовка → драйвер → llama.cpp → модель → сервис.

Модель: [Dirk-Qwen3.8-27B-GGUF](https://huggingface.co/peculiar-ragdoll/Dirk-Qwen3.8-27B-GGUF) — dense 27B, Sharp template, vision, MTP.

## Dirk — API key + systemd сервис ✅



### API key — `/etc/llama/api.key`

Общий ключ для **всех** LLM-серверов (Dirk на 236, Tiel на 220). **Одинаковое содержимое** на обеих GPU-VM — в Cursor тот же ключ для обеих моделей.

Файл:

```
/etc/llama/api.key
```

**Заменить ключ:** `sudo nano /etc/llama/api.key` → вставить новое значение **одной строкой** → сохранить (Ctrl+O, Enter, Ctrl+X):

```bash
sudo chmod 600 /etc/llama/api.key
sudo chown openfun:openfun /etc/llama/api.key
sudo systemctl restart dirk
```

**Первое создание** (или перенос с `/etc/dirk/api.key`):

```bash
sudo mkdir -p /etc/llama
sudo nano /etc/llama/api.key          # вставить ключ, сохранить
sudo chmod 600 /etc/llama/api.key
sudo chown openfun:openfun /etc/llama/api.key
```

> Сервис работает от **openfun** — владелец файла должен быть `openfun:openfun`. Содержимое сейчас: `openfun:openfun`.



### `/etc/systemd/system/dirk.service`

```bash
sudo nano /etc/systemd/system/dirk.service
```

Вставить целиком:

```ini
[Unit]
Description=Dirk Qwen3.8-27B llama.cpp server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=openfun
Group=openfun
WorkingDirectory=/home/openfun/models

ExecStart=/home/openfun/llama.cpp/build/bin/llama-server \
  -m /home/openfun/models/Dirk-Qwen3.8-27B-UD-IQ4_XS.gguf \
  --mmproj /home/openfun/models/mmproj-F16.gguf \
  --image-min-tokens 1024 \
  --image-max-tokens 2048 \
  --flash-attn on \
  --api-key-file /etc/llama/api.key \
  --reasoning-format deepseek \
  --spec-type draft-mtp \
  --spec-draft-n-max 2 \
  -ngld 99 \
  -ngl 99 \
  --jinja \
  -np 1 \
  -c 204800 \
  -ctk q8_0 \
  -ctv q8_0 \
  --top-p 0.95 \
  --top-k 20 \
  --min-p 0 \
  --host 0.0.0.0 \
  --port 8080

Restart=on-failure
RestartSec=10
TimeoutStartSec=600

[Install]
WantedBy=multi-user.target
```



### Параметры (кодинг + агент)


| Параметр                             | Зачем                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------- |
| `--jinja`                            | Sharp chat template ([Dirk](https://huggingface.co/peculiar-ragdoll/Dirk-Qwen3.8-27B-GGUF)) |
| `--reasoning-format deepseek`        | thinking → `reasoning_content`, не ломает tool calls                                        |
| `--spec-type draft-mtp` + `-ngld 99` | MTP ускорение generation                                                                    |
| `-np 1`                              | иначе KV ×4 → OOM                                                                           |
| `-c 204800` + q8_0 KV                | 200K под Cursor, точная память диалога                                                      |
| `--image-min-tokens 1024`            | OCR / скрины / grounding (Qwen-VL)                                                          |
| `--image-max-tokens 2048`            | баланс vision и VRAM                                                                        |


**Thinking** — в запросе клиента, не в unit:

```json
"chat_template_kwargs": { "reasoning_effort": "xhigh" }
```

Дефолт Dirk: **medium**. Уровни: `low`, `medium`, `xhigh`. Выключить: `"enable_thinking": false`.

**Не ставить:** `--reasoning-format none`.

## ⚠️ Важно — предупреждения и обслуживание

### VRAM и контекст

- **IQ4_XS + 200K q8_0** — финальная сборка; запас **~670 MB**.
- Vision на больших скринах может OOM — не поднимать `--image-max-tokens` выше 2048.
- Если OOM: `-c 184320` (180K) или `--image-max-tokens 1024`.
- **Q4_K_XL** на 24 GB не тянет q8_0 KV на 200K — нужен **IQ4_XS**.



### Vision

- **min 1024** — must-have для Qwen-VL ([issue #16842](https://github.com/ggml-org/llama.cpp/issues/16842)).
- **max 2048** + `--flash-attn on` при текущем запасе VRAM.



### Thinking (Dirk)

- Дефолт **medium** — lean coding.
- Сложные задачи: `"reasoning_effort": "xhigh"` в `chat_template_kwargs`.



### UFW / обновления

- Не удалять **OpenSSH** из UFW.
- После `apt upgrade` + reboot → `nvidia-smi`, `systemctl status dirk`.
- `git pull` llama.cpp → пересборка, `systemctl restart dirk`.

### API key

- **`/etc/llama/api.key`** — не коммитить. Замена: `sudo nano /etc/llama/api.key`, затем `systemctl restart dirk`.
