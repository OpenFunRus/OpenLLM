# Ubuntu 24.04 + RTX 2080 Ti 22GB — headless AI server

Успешные шаги записываются сюда. Порядок: подготовка → драйвер → llama.cpp → модель → сервис.

---

## Подготовка — SSD 128G, расширение `/` (LVM) ✅

Hostname: **u24r2080**. LAN: **192.168.1.220**.

После чистой установки Ubuntu часто видит только половину диска на `/`. Проверка:

```bash
sudo hostnamectl set-hostname u24r2080
lsblk
df -h /
```

Если `sda3` ~125G, а `/` ~62G — во volume group есть свободное место, расширяем:

```bash
sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
sudo resize2fs /dev/ubuntu-vg/ubuntu-lv
df -h /
```

Результат: `/` ~123G, ~100G свободно.

## Драйвер NVIDIA 580-server (headless) ✅

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential dkms linux-headers-$(uname -r) mokutil
echo -e "blacklist nouveau\noptions nouveau modeset=0" | sudo tee /etc/modprobe.d/blacklist-nouveau.conf
sudo update-initramfs -u
sudo apt install -y nvidia-headless-580-server nvidia-utils-580-server
sudo reboot
nvidia-smi
```

## Tiel-Coder — API key + systemd сервис ✅

### API key — `/etc/llama/api.key`

Общий ключ для **всех** LLM-серверов (Tiel на 220, Dirk на 236). **Одинаковое содержимое** на обеих GPU-VM — в Cursor тот же ключ для обеих моделей.

Файл:

```
/etc/llama/api.key
```

**Заменить ключ:** `sudo nano /etc/llama/api.key` → вставить новое значение **одной строкой** → сохранить (Ctrl+O, Enter, Ctrl+X):

```bash
sudo chmod 600 /etc/llama/api.key
sudo chown openfun:openfun /etc/llama/api.key
sudo systemctl restart tiel-coder
```

**Первое создание** (или перенос с `/etc/tiel-coder/api.key`):

```bash
sudo mkdir -p /etc/llama
sudo nano /etc/llama/api.key          # вставить ключ, сохранить
sudo chmod 600 /etc/llama/api.key
sudo chown openfun:openfun /etc/llama/api.key
```

> Сервис работает от **openfun** — владелец файла должен быть `openfun:openfun`. Содержимое сейчас: `openfun:openfun`.

### Создание `/etc/systemd/system/tiel-coder.service`

```bash
sudo nano /etc/systemd/system/tiel-coder.service
```

Вставить в файл целиком:

```ini
[Unit]
Description=Tiel-Coder 35B llama.cpp server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=openfun
Group=openfun
WorkingDirectory=/home/openfun/models

ExecStart=/home/openfun/llama.cpp/build/bin/llama-server \
  -m /home/openfun/models/Tiel-Coder-35B-A3B-UD-IQ4_XS.gguf \
  --mmproj /home/openfun/models/mmproj-BF16.gguf \
  --image-min-tokens 1024 \
  --image-max-tokens 2048 \
  --api-key-file /etc/llama/api.key \
  -ngl 99 \
  --jinja \
  -np 1 \
  -c 204800 \
  -ctk q8_0 \
  -ctv q8_0 \
  --temp 0.6 \
  --top-p 0.95 \
  --top-k 20 \
  --host 0.0.0.0 \
  --port 8080

Restart=on-failure
RestartSec=10
TimeoutStartSec=600

[Install]
WantedBy=multi-user.target
```

Сохранить (Ctrl+O, Enter, Ctrl+X), затем автозапуск:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tiel-coder
sudo systemctl status tiel-coder
```

Проверка:

```bash
journalctl -u tiel-coder -f
curl -s http://127.0.0.1:8080/health
nvidia-smi
```

Ожидаем: `{"status":"ok"}`, VRAM **~20531 MiB / 22528 MiB** (~2 GB запас), `llama-server` ~20528 MiB.

## ⚠️ Важно — предупреждения и обслуживание

### Vision: `--image-min-tokens 1024`, `--image-max-tokens 2048`

**Must-have** для Qwen-VL / Tiel: без 1024 хуже читаются скрины с кодом, stack trace, grounding («где на картинке ошибка»).

**max 2048** — баланс vision и VRAM на 22 GB; не поднимать выше без запаса по `nvidia-smi`.

**Риск OOM:** idle **20531 / 22528 MiB** (модель + mmproj + KV 200K q8_0). Vision-запрос **добавляет** нагрузку — возможен **OOM** на больших картинках или при активном контексте.

**Проверка после vision-запроса:**
```bash
nvidia-smi
journalctl -u tiel-coder -n 30 --no-pager
```
Если падает — уменьшить `-c` (например `196608` / 192K), `--image-max-tokens 1024`, или тестировать vision отдельно с меньшим контекстом.

### VRAM и контекст 200K

- **IQ4_XS + mmproj + 204800 ctx + q8_0 KV** — проверено: idle **20531 MiB / 22528 MiB** (~**1997 MiB** запас).
- Одновременно несколько клиентов / длинный чат / vision → следить за `nvidia-smi`.
- Автор Tiel: для agentic coding **temp 0.6** (у нас в сервисе); для болталки — **1.0** (менять в unit или в запросе клиента).

### UFW и SSH

- Никогда не удалять **`OpenSSH` / порт 22** из UFW.
- Перед `ufw enable` — правило SSH уже добавлено; держать запасную SSH-сессию.

### Обновления системы

- `apt upgrade` + новое **ядро** → может понадобиться **reboot**; после reboot — `nvidia-smi`, `systemctl status tiel-coder`.
- Обновление **драйвера NVIDIA** — только осознанно, после reboot проверить GPU и сервис.

### Secure Boot (если переустановка)

При **Secure Boot enabled** — при установке драйвера пароль **MOK**, после reboot экран Enroll MOK (нужен монитор+клавиатура на headless).

### llama.cpp / модель

- После `git pull` в llama.cpp — пересборка и `systemctl restart tiel-coder`.
- Модель ~18 GB + mmproj ~1 GB — следить за местом на `/` (`df -h /`).

### API key

- **`/etc/llama/api.key`** — не коммитить, не светить в логах клиентов. Замена: `sudo nano /etc/llama/api.key`, затем `systemctl restart tiel-coder`.
