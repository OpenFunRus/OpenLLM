## 2. Размеры и стили текста

Очень **жирный** текст для акцентов.
*Курсивный* текст для выделения понятий.
___Подчёркнутый курсивом (triple underscore)___ текст.
~~Зачёркнутый~~ текст для удалённых пунктов.
**_Жирный курсив_** — комбинированные стили.
`инлайн-код` внутри текста.
> Блок цитаты (blockquote) для ссылок на чужие слова.

| Стиль | Пример |
|:-----:|:------:|
| Жирный | **Bold** |
| Курсив | *Italic* |
| Зачёркнутый | ~~Strikethrough~~ |
| Инлайн-код | `code()` |
| Комбо | **_bold italic_** |

## 5. Код

### Инлайн
Используй функцию `Math.random()`, чтобы генерировать числа.

### Блок кода без подсветки
```
for (let i = 0; i < 10; i++) {
  console.log("Шаг", i);
}
```

### Блок кода с JavaScript
```javascript
function snakeStep(dir, snake) {
  const head = {
    x: snake[0].x + dir.x,
    y: snake[0].y + dir.y
  };
  return [head, ...snake.slice(0, -1)];
}
```

### Блок кода с CSS
```css
.title {
  color: #4ade80;
  text-shadow: 0 0 20px rgba(74, 222, 128, 0.5);
  letter-spacing: 2px;
}
```
